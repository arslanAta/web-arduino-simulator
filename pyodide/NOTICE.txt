Pyodide 314.0.8 (https://pyodide.org), the Python interpreter the Raspberry Pi boards run
their programs on. These are the unmodified runtime files of the npm package `pyodide`:
pyodide.mjs (with its source map), pyodide.asm.mjs, pyodide.asm.wasm, python_stdlib.zip,
pyodide-lock.json.
